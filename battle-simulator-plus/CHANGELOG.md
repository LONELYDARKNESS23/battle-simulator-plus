# Изменения

## 1.1.0 — 2026-10-08

- Растровые бойцы и грунт, детали брони, оборудования и укрытий.
- Направление взгляда по движению, стрельбе, лечению и ответному огню; совместимость со старыми сохранениями.
- Анимация движения по фактическому маршруту.
- Быстрый старт, крупная карта и переход к следующему бойцу с ОД.
- Запуск без консоли, повторное открытие того же сеанса и выход из игры.
- Проверки направления, отмены, сохранений, запуска и состава релиза.


## 1.0.0

Первый подготовленный выпуск RIFT.

- Тактический бой с тремя картами, четырьмя классами, узлами контроля и детерминированным уроном.
- Взаимозаменяемые командиры: встроенный ИИ, Ollama и совместимые Chat Completions API.
- Реальные конечные позиции и маршруты в журнале при прерывании движения ответным огнём.
- Полная проверка типов и координат сохранений; ошибки файлов не ломают интерфейс.
- Ход ИИ применяется целиком после успешного исполнения на копии состояния; резервный ход восстанавливает управление при сбое.
- Старые ответы модели и устаревшие команды из другой вкладки не изменяют текущий бой.
- Кеш линий огня и маршрутов к целям, сокращение перебора клеток для гранаты, компактные ответы при неизменном состоянии.
- Перерисовка карты при изменениях и анимациях; фон кешируется, скрытая вкладка не обновляет бой автоматически.
- Пауза наблюдения кнопкой и клавишей P; отмена своего последнего победного действия.
- Раздельные ручной и автоматический слоты, уникальные временные файлы для атомарных записей.
- Запуск на Windows, Linux и macOS, отдельные профили через `--data-dir`.
- Автоматические проверки GitHub Actions, тесты интерфейсного контроллера и чистый исходный ZIP.
